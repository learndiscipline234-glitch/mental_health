About this project

This is a machine-learning portfolio project. A scikit-learn model, served by a FastAPI backend, estimates a mental health score from age, country, academic level, social media habits, sleep, study time, physical activity and stress level.

The model learns patterns from a survey dataset. It shows correlations, not causes, and it can't assess any individual. If you're struggling, please talk to a qualified professional.

Built with HTML, CSS, JavaScript, FastAPI and scikit-learn. For education only.
